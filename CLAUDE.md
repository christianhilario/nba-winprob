# CLAUDE.md — nba-winprob

## What this project is
DS340 (intro ML, BU, Fall 2026) final project by Chris and David. Predict home-team win probability after every NBA play-by-play event. Compare logistic regression, gradient boosting, LSTM (stretch: transformer). Final test is prospective on 2026-27 games, models frozen beforehand. Due **Dec 8, 2026** (paper + lightning talk).

## Hard rules (call these out if violated)
1. **No leakage.** Split by game AND by season (train earlier seasons, validate later, test 2026-27). Never split by event. Pregame Elo must only use games completed *before* that game's date. Scalers/encoders fit on train only.
2. **Nontrivial predictions (prof feedback).** Score diff late in a game makes prediction trivial. Every headline metric must also be reported on the "contested" subsets defined in `docs/EVALUATION.md`, and models compared to the score+time baseline, not just to chance.
3. **Interpretability (prof feedback).** Report LR standardized coefficients, GBM feature importances (gain + permutation), and feature-group ablation/permutation for LSTM/transformer. See `docs/EVALUATION.md`.
4. Freeze models (save weights + config + git hash) before touching 2026-27 test games.
5. Random seeds set everywhere; results tables generated by code into `reports/`.
